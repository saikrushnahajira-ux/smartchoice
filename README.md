# AI House Price Prediction Platform

A production-quality Machine Learning Web Application for real estate valuation.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Train model: `python train_model.py`
3. Run website: `python app.py`
4. Open browser at `http://localhost:3000`

## Deploy to Vercel
Push repository to GitHub, connect to Vercel, and auto-deploy!
